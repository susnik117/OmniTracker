# OMNITRACKER (Техзадачи)
название класса, реализующий окно приложения: OmniTracker с родительским классом QMainWindow

## 1. ГЛАВНАЯ ПАНЕЛЬ
Главная панель должна будет состоять из нескольких элементов:
1. Философских цитат (выбор цитаты будет определяться через библиотеку random). Текст будет появляться на QLabel, название ярлыка: phylosophy_label
2. Рисунки (будут загружаться через pixmap'ы)
3. Графики 
    - За что будет отвечать каждый график:
        1. График1: будет отвечать за суммарное кол-во очков, полученных за день в течении недели. Можно будет сравнить, сколько было заработано баллов/выполнено заданий за дни в текущей недели. При переходе на следующей недели, график сбрасывается. *(если какое-либо значение полученных баллов за день ушло в отрицательную величину, показывает лишь число)*
        2. График2: будет отвечать за суммарное кол-во очков, полученных за день в течении одного месяца. График сбрасывается при смене месяца.  *(если какое-либо значение полученных баллов за день ушло в отрицательную величину, показывает лишь число, график резко прерывается и продолжается с того момента, когда значение полученных баллов за день неотрицательно)*
        3. График3: будет отвечать за кол-во очков, полученных по критерию Важность/Срочность (по заводским настройкам. Критерий можно сменить). График рассчитывается в течении одного месяца. График сбрасывается при смене месяца. *(Если возможные значения выбранного критерия будут больше/меньше промежутка от 1 до 5, то это легко исправляется с помощью layout'ов)*
        4. График4: будет отвечать за то, выполнил ли пользователь задачи в срок/отменил задачу в течении месяца. График сбрасывается при смене месяца
4. Лист, на котором будут показаны сегодняшние задачи. Задачи будут браться из ежедневника и планировщика (если задача на сегодняшнюю дату/дедлайн до сегодняшнего дня). *(задачи из планировщика будут подчёркиваться и выводится в самый вверх, а сам текст будет более крупным шрифтом.)* Выполненные задачи будут вычеркнуты. Задачи на главном экране
5. Кнопка "+", plus_button. Является объектом класса PushButton Нажав на неё, пользователю даётся выбор выбрать, к какому из инструментов (задачник, ежедневник, планировщик) надо добавить задачу
6. Над приложением будут расположены несколько вкладок: глав. панель, задачник, ежедневник, планировщик, результаты и настройки. При переходе на них пользователя будет перекидывать в соответствии с выбранной вкладкой

## 2. ЗАДАЧНИК
*Название класса: ToDo*
### ПРИ НАЖАТИИ КНОПКИ "+"
При нажатии на кнопку "+" и последующем выборе Задачника, пользователю будет предоставлено следующие строки для заполнения:
1. Название задачи (является QLineEdit, имеет имя name. Нельзя создавать задачи с похожими именами, только уникальные)
2. Критерии (кроме тех, которых пользователь отметил, что их нужно проверять после выполнения задачи. См 5, Систем вознаграждения) *(Дедлайны будут выровнены по layout'у для того, чтобы если критериев больше 3, они не занимали места для Дедлайна и 3-го пункта)*
3. (Если задача уже существует и пользователь хочет переместить её в Задачник) выбрать уже существующую задачу и переместить её в задачник. *(Является QPushButton, имеет имя add_existing_task. Если заполнено имя, то имя у задачи переименовывается. Если критерии заполнены, то у задачи переделываются критерии)*
    - При нажатии на этот пункт, справа открывается окошко с существующими задачами из списка задач, ежедневника и планировщика. Задачи в этом окошке будут являться объектами класса QRadioButton
4. Кнопка "добавить". (Является объектом класса PushButton, имя: add_btn. Добавляет в todo.csv задачу)

### ПРИ ЗАХОДЕ ВО ВКЛАДКУ
При обычном заходе на вкладу, пользователя встречает окошко с текущими задачами (выполненными и теми, над которыми всё ещё стоит поработать) *(Задачи являются QCheckBox'ами)*. Если нажать на какое-либо из них, то справа откроется окошечко с описанием задачи. 
- Правое окошко будет содержать:
    1. Описание задачи (имя, критерии)
    2. Кнопка "Изменить" (PushButton, edit_task_btn. Перемещает в панель "При нажатии кнопки '+'")
    3. Кнопка "Удалить" (PushButton, delete_task_btn. Перед удалением спрашивает подтверждение. Удаляет задачу из приложения и всех файлов, где она была записана) 

В левом окошке, если нажать на QCheckBox с той или иной задачей, то текст задачи зачеркнётся

## 3. ЕЖЕДНЕВНИК
*Название класса: Diary, родительский класс: ToDo*
### ПРИ НАЖАТИИ КНОПКИ "+"
Открывается почти такое же окно, как и в Задачнике, но при составлении задачи **критериев у задач в Ежедневнике нет**

### ПРИ ЗАХОДЕ ВО ВКЛАДКУ
Открывается почти такое же окно, как и в Задачнике, кроме того, что с правой стороны отображается время, в которое задачу нужно выполнить (и отображаются только те задачи, которые назначены на сегодяшний день недели). С правой стороны отображается у задачи отображаются её время и дни недели, а также снизу кнопки "Изменить" и "Удалить" 

## 4. ПЛАНИРОВЩИК
*Название класса: Schedule, родительские классы: ToDo и Diary*
### ПРИ НАЖАТИИ КНОПКИ "+"
Открывается окно с левой стороны которого календарь (является объектом класса QCalendarWidget). Если нажать на какой-либо день, откроется 2 панели справа, первая (с левой стороны): панель добавления критериев к заданию (а также QCheckBox с возможностью добавить уже существующую задачу), а в самой правой стороне панель с уже существующими заданиями (Изначально: QListWidget. Если нажать на ранее сказанный QCheckBox, то из каждой задачи в QListWidget возмётся текст и на их место встанет QRadioButton. Все эти кнопки будут относится к одной группе)

Снизу будет возможность выбрать имя для задачи (QLineEdit) и выбрать время, в которую её нужно выполнить (QTimeEdit), а также кнопка добавить в панели с критериями

### ПРИ ЗАХОДЕ ВО ВКЛАДКУ
Открывается почти такое же окно, как и при нажатии на кнопку "+", за исключением того, что здесь уже две панели: календарь (левая, объект QCalendarWidget) и уже существующие задачи (правая, QListWidget). При нажатии на один из каких либо задач, справа откроется ещё панель, где можно отредактировать уже текущую задачу

## 5. СИСТЕМА ВОЗНАГРАЖДЕНИЯ (ИЛИ ЖЕ РЕЗУЛЬТАТЫ)
### САМА СИСТЕМА ВОЗНАГРАЖДЕНИЯ
Из файла criterions.scv при создании задачи достаются все критерии (кроме тех, которых пользователь отметил, что их нужно отмечать после выполнения задачи) в интерфейс, пользователь может выбрать численное значение критериев. После создания, численные значения критериев записываются в results.csv под соответствующим критерием. После окончания задания пользователю предлагают также оценить задачу по тем критериям, по которым пользователь просил отмечать после выполнения задачи

### ГРАФИКИ
При заходе во вкладку "Результаты" перед пользователем появляется две панели для выбора графика и даты в нём (График1 будет отображать неделю, в которой данная дата стоит. Остальные будут отображать месяца, в которой эта дата стоит). Выбор графика и последующую дату отобразит график из выбранного промежутка времени (информация будет браться из results.csv)

*При построении графика будет использоваться библиотека Matplotlib*

## 6. НАСТРОЙКИ

### КРИТЕРИИ
*(можно создать не более 5 критериев)*
При создании пользователем новых критериев, они будут помещаться в файл criterion, иметь уникальное имя, и мин/макс очков за него. Шаблон:
name,min,max (где name -- имя критерия, min -- минимальное кол-во очков, max -- максимальное)
*Минимальное возможное значение критерия для минимума будет равно 0, а максимальное -- 10. Если пользователь сделает min = 3, а max = 6, то приложение будет показывать, что за это задание можно получить от 1 до 3 баллов, вместо от 3 до 6 баллов*

### ЧТО МОЖНО БУДЕТ НАСТРОИТЬ
1. Кол-во критериев и их мин/макс значение (Как уже было сказано)
2. Через сколько дней пропадает задача из интерфейса после её выполнения
3. Цитаты на глав. панеле
4. Рисунки на глав. панеле

## 7. ХРАНЕНИЕ ДАННЫХ
- *Философские цитаты* будут храниться в файле phylosophy.csv
    > (Шаблон) id,quote (где id -- уникальное значение, а quote -- сама цитата)
- Результаты *графиков* будут храниться в файле results.csv
    > (Шаблон) date,task,criterion,num (где date -- дата добавления численного значения критерия за задачу, task -- задача, criterion -- критерий)
- Шаблоны:
    > (График1) date,week,days (где date -- дата сброса графика, week -- номер недели, а days -- в какой день сколько очков было получено. Days будет представлен в виде списка в хронологии Пн-Вс)
    > (График2) date,month,days (где date -- дата сброса графика, month -- номер месяца, а days -- в какой день сколько очков было получено. Days будет представлен в виде списка в хронологии Пн-Вс) 
    > (График3) date,month,criterion (где date -- дата сброса графика, month -- номер месяца, а criterion -- критерий, по которому выводится кол-во баллов)
    > (График4) date,compl,disc (где date -- дата сброса графика, compl -- кол-во выполненных задач, disc -- кол-во отменённых/просроченных задач)
- Задачи из *задачника* будут записываться в файле todo.csv
    > (Шаблон) name,[criterion1-5] (где name -- название задачи, а criterion1-5 -- численные значения помещённых в лист критериев задачи)
- Задачи из *ежедневника* будут записываться в файле diary.csv
    > (Шаблон) name,time,repeat (где name -- название задачи, time -- время, в которое нужно выполнить задачу, repeat -- дни недели, в которые задачи должны выполняться. name должно быть уникальным)
- Задачи из *планировщика* будут записываться в файле schedule.csv
    > (Шаблон) date,name,time,[criterion1-5] (где date -- дата выбранного дня, name -- имя задачи, time -- время, в которое задача должна быть выполнена. name должно быть уникальным, а criterion1-5 -- численные значения помещённых в лист критериев задачи)
- *Критерии* будут хранится в файле criterions.csv 
    > (Шаблон) name,min,max (где name -- имя критерия, min -- минимальное кол-во очков, max -- максимальное)
